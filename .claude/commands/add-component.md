description: 21st.dev 등에서 복사한 컴포넌트(프롬프트)를 이 프로젝트에 맞게 넣습니다
---
사용자가 외부 컴포넌트를 넣고 싶어 합니다. 붙여넣은 내용:

$ARGUMENTS

다음 순서로 진행하세요.

1. **구현하기 전에** 아래를 짧게 정리해서 보여주고 허락을 받으세요.
   - 이 컴포넌트가 무엇을 하는지 (한 줄)
   - 새로 설치해야 할 패키지 목록 (없으면 "없음")
   - 어느 페이지·섹션에 넣을지 제안 (예: 기존 Hero 대체, 새 섹션 추가)
2. 허락을 받으면:
   - 원본 부품 파일은 `components/ui/` 에 넣습니다. (폴더가 없으면 만듭니다)
   - 필요한 패키지를 설치합니다.
   - `components/` 에 새 섹션 파일을 만들어 부품을 감싸고, `mode`(ani / fine)를 받도록 합니다.
   - 데모의 영어 문구는 한국어 예시 문구로 바꿉니다. 관리자에서 바꿔야 할 글이면 그렇게 할지 물어보세요.
   - 기존 섹션 파일은 지우지 말고 페이지 파일(`app/.../page.tsx`)에서만 바꿔 끼웁니다.
3. `npm run build` 로 에러가 없는지 확인합니다.
4. 브라우저에서 어디를 보면 되는지, 되돌리려면 어떻게 말하면 되는지 알려주세요.
