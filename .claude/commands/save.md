지금까지의 변경을 git 커밋으로 저장해 주세요. 메모: $ARGUMENTS

1. `git status` 로 바뀐 파일을 확인하고, 어떤 변경인지 쉬운 말로 한 줄씩 요약해 보여주세요.
2. `.env.local` 같은 비밀 파일이 포함되지 않았는지 확인하세요.
3. 한국어로 짧은 커밋 메시지를 만들어 커밋하세요. (메모가 있으면 반영)
4. push 는 하지 마세요. 끝나면 "GitHub에 올리려면 /check 후 push 를 요청하세요"라고 안내하세요.
