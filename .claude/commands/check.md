배포 전 점검을 해 주세요. 파일은 수정하지 말고 점검 결과만 알려주세요. (문제가 있으면 고칠지 물어보기)

1. `npm run lint` 실행 → 경고/에러 요약
2. `npm run build` 실행 → 성공 여부. 실패하면 원인을 쉬운 말로 설명
3. `git status` 로 저장(커밋)하지 않은 변경이 있는지 확인
4. 코드 안에 비밀 키나 비밀번호가 직접 적혀 있지 않은지 확인 (`.env.local` 파일 자체는 열지 말 것)
5. 관리자 기능이 서버에서 권한을 확인하는지 훑어보기 (브라우저에서만 확인하는 곳이 있으면 ⚠️)
6. Vercel 에 등록해야 할 환경변수 **이름** 목록 안내 (코드에서 `process.env.` 로 쓰는 이름을 찾아서)

마지막에 ✅/⚠️ 표시로 한눈에 보이는 체크리스트로 정리해 주세요.
